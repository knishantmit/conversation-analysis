# Conversation Analysis
Analyze a dataset of conversations consisting of customers queries related to banking and responses of human agents.

# Problem
- Generate impactful conversational insights that can be helpful in decision making to optimize a conversational bot.
- Generate a customer satisfaction score for each conversation.

# Dataset
Conversation between Customers and Human Agents.
1. **conversation_id** : Unique Id for each Conversation. There would be multiple rows as conversation is stored for every utterance (Customer or Agent) for the same conversation.
2. **speaker**: Customer Support Agent OR Customer.
3. **date_time**: Data & time of each utterance
4. **text**: Conversation Dialogue.
